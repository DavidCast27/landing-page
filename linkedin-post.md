# Borrador Post LinkedIn - Landing Page Template

hace un tiempo un amigo me dijo: *"Parce necesito una landing page para un emprendimiento. ¿Me echas una mano?"*

Podría haber montado una web sencilla desde cero y cerrar el tema, pero decidí ir un paso más allá. El objetivo era construir algo que no solo le sirviera a él, sino que se convirtiera en una herramienta definitiva para cualquiera que necesite levantar una web profesional, veloz y con **mantenimiento a costo cero**.


Así le di forma a este **Astro Landing Template** 🚀, un proyecto open source pensado para ser clonado y usado en minutos.

¿Cómo lo estructuré? Aquí la magia:

🖊️ **Panel de Administración Real (Sin servidores extra):** Integré **Decap CMS**. Quería que mi amigo pudiera modificar sus servicios, textos e imágenes por su cuenta, sin tocar código y **sin pagar mensualidades por plataformas cerradas**. Él entra a `/admin`, edita visualmente los contenidos, y por detrás esos cambios se guardan limpiamente como archivos YAML/Markdown en el repositorio (Git-based CMS).
⚡️ **Velocidad y SEO al Máximo:** Escogí **Astro** para asegurar que el HTML generado estuviese completamente optimizado para los buscadores (SEO) ofreciendo tiempos de carga casi instantáneos.
🌍 **Nació como web, creció como Template:** Lo diseñé genérico y escalable intencionalmente. Viene configurado con enrutamiento multilingüe de fábrica (Inglés, Español, Francés). La idea es que cualquiera haga un fork, ajuste sus colores base con Tailwind, suba sus imágenes y despliegue gratis en plataformas como Vercel o Netlify.

**En resumen, ¿qué lo hace especial?**
✅ **Astro Framework:** Performance brutal y SEO 100/100 por defecto.
✅ **Decap CMS:** Gestión de contenido tipo "Admin" para no técnicos, $0 costo extra de hosting.
✅ **i18n Nativo:** Listo para operar en Inglés, Español y Francés.
✅ **Tailwind CSS & TypeScript:** Código limpio, tipado y fácil de personalizar.

Es un proyecto **100% Open Source**. Si buscas una base sólida y gratuita para tu próxima landing, este es tu punto de partida.
